4.2 Migrating to PQC: how the world switches

Swapping the cryptography of the whole internet is a huge job. Here is how it is being done.

Hybrid key exchange

PQC schemes are young. To be safe during the transition, systems run a classical and a post-quantum key exchange together and combine the results:

Why it is safe. An attacker must break both. With a quantum computer they can recover K₁, but K₂ is still unknown, and hashing K₁ together with an unknown K₂ gives a key they know nothing about. And if ML-KEM ever had a flaw, X25519 still protects today's traffic.

This hybrid, called X25519MLKEM768, has been switched on by default in major browsers and large websites since 2024. Messaging apps such as Signal and iMessage added post-quantum protection in 2023 and 2024.

Steps for an organization

  1. Inventory: find every place that uses RSA, Diffie–Hellman or ECC: websites, VPNs, code signing, smart cards, databases.
  2. Prioritize: data that must stay secret for years (Mosca's rule, 1.2) and systems that are hard to update come first.
  3. Crypto-agility: design systems so the algorithm can be swapped by changing a setting, not rewriting software.
  4. Test and deploy: start with hybrids, watch for problems with larger messages, then move fully to PQC.

PQC and QKD together

PQC (this course)Software on existing devices and networks. Security rests on maths problems believed hard. Works everywhere, at internet scale.
QKD (quantum key distribution, Part 6)Sends keys using single particles of light. Special hardware and dedicated links. Security rests on physics. Limited distance, but immune to any future maths breakthrough.

Most experts see PQC as the main answer for everyday use, with QKD as an extra layer for a few high-value links.
