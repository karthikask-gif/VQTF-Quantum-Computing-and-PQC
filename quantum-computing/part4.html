Part 4 · Dirac Notation

The short-hand that every quantum book uses, explained one symbol at a time.

4.1 Why a special notation?

In Part 3 we wrote qubit states as lists of numbers, like [0.71, 0.71]. That works for one qubit, but it quickly gets messy: 10 qubits need a list of 1,024 numbers.

In 1939 the physicist Paul Dirac came up with a neater way to write states. Instead of the full list, you write a short name inside a special bracket. It's like writing "Mum's house" instead of a full street address: shorter, clearer, and everyone knows what you mean.

Ket |ψ⟩A state. Points to the right.
Bra ⟨ψ|The "mirror image" of a state. Points to the left.
Bracket ⟨a|b⟩A bra and a ket joined: gives one number, the overlap.
Ket-bra |a⟩⟨b|A ket and a bra the other way round: gives a matrix, a machine.
The name is a pun: a bra plus a ket makes a bra-ket, a "bracket". So it is also called bra-ket notation.

4.2 Kets |ψ⟩: writing a state

A ket is a vertical bar and an angle bracket around a name: |name⟩. It always means "the state called name". Behind the scenes, a ket is a column of numbers.

KetRead aloudColumn of numbersMeaning
|0⟩"ket zero"10Surely 0
|1⟩"ket one"01Surely 1
|+⟩"ket plus"0.710.7150/50, parts in step
|−⟩"ket minus"0.71−0.7150/50, parts opposite
|ψ⟩"ket psi"αβAny state: α of 0, β of 1

The name inside can be anything: a number, a sign, or a Greek letter like ψ ("psi", said "sigh"). Greek letters are just the usual way to say "some state we haven't named yet".

Writing a mix. Because |0⟩ and |1⟩ are columns, we can add them like any lists of numbers:
0.6|0⟩ + 0.8|1⟩ = 0.6 × 10 + 0.8 × 01 = 0.60.8
The Dirac version on the left is shorter and tells you at a glance: amplitude 0.6 for 0 and 0.8 for 1, so chances of 0.6² = 36% and 0.8² = 64%.

4.3 Bras ⟨ψ|: the mirror image

A bra is a ket flipped around: ⟨name|. It stands for the same state, but written as a row instead of a column. You can think of it as the state looking at its reflection in a mirror.

There is one extra rule. If the numbers are complex (they contain i), every +i becomes −i and every −i becomes +i in the bra. This is called taking the conjugate. For ordinary numbers nothing changes.

Ket (column)Bra (row)
|0⟩ = 10⟨0| = 10
|+⟩ = 0.710.71⟨+| = 0.710.71
|+i⟩ = 0.710.71i⟨+i| = 0.71−0.71i (the i flips sign)

On its own, a bra doesn't do much. It is waiting to meet a ket, which is the next step.

4.4 Bra + ket = bracket ⟨a|b⟩: how alike are two states?

When a bra meets a ket, their bars merge into one and you get a bracket: ⟨a|b⟩. The answer is always a single number. It measures how much the two states overlap:

⟨a|b⟩ = 1The same state.
⟨a|b⟩ = 0Completely different (called orthogonal). A measurement can always tell them apart.
In betweenPartly alike. The overlap squared is a chance.

How to work it out: it is just "row times column" from Part 3. Multiply the matching numbers and add them up.

⟨0|+⟩ = 10 × 0.710.71 = 1 × 0.71 + 0 × 0.71 = 0.71

Why it matters: the overlap squared, |⟨a|b⟩|², is the chance that a qubit in state b gives the answer "a" when you check for a. Above, 0.71² = 0.5, so |+⟩ gives 0 half the time. This is the measuring rule from Part 3, written in one short line.

4.5 Ket-bra |a⟩⟨b|: building a machine

Now put them the other way round: ket first, then bra, |a⟩⟨b|. This time the result is not a number but a matrix, a machine that changes states (Part 3, 3.4).

Step 1: what the machine does

Watch what happens when the machine meets a ket. The bra on the right "checks" the incoming state, and the ket on the left is what comes out:

Recipe: ( |a⟩⟨b| ) |ψ⟩ = |a⟩ × ⟨b|ψ⟩
Read it as: "check how much of b is in ψ, then output that much of a".

Step 2: how to build its matrix

A ket is a column and a bra is a row. Multiplying a column by a row fills a 2×2 grid. Each box is:

(number in that row of the ket) × (number in that column of the bra)

Example: |1⟩⟨0|. The ket |1⟩ is the column 01 and the bra ⟨0| is the row 10.
Top row of the grid uses the ket's top number (0): 0×1 = 0, 0×0 = 0.
Bottom row uses the ket's bottom number (1): 1×1 = 1, 1×0 = 0.
So |1⟩⟨0| = 0010.

The same rule gives the four basic building blocks:

Ket-braColumn × rowMatrixWhat it does
|0⟩⟨0|10 × 101000A filter: keeps the 0 part, throws away the 1 part
|0⟩⟨1|10 × 010100Takes the 1 part and turns it into 0
|1⟩⟨0|01 × 100010Takes the 0 part and turns it into 1
|1⟩⟨1|01 × 010001A filter that keeps only the 1 part

Step 3: adding machines together

To add two machines, add their grids box by box (top-left plus top-left, and so on). The new machine does both jobs at once.

Swap = |0⟩⟨1| + |1⟩⟨0|.
0100 + 0010 = 0+01+00+10+0 = 0110
It turns 1 into 0 and 0 into 1: the swap matrix from Part 3. Check with the recipe: (|0⟩⟨1| + |1⟩⟨0|)|0⟩ = |0⟩×⟨1|0⟩ + |1⟩×⟨0|0⟩ = |0⟩×0 + |1⟩×1 = |1⟩.
Identity = |0⟩⟨0| + |1⟩⟨1|.
1000 + 0001 = 1+00+00+00+1 = 1001
It keeps the 0 part and keeps the 1 part, so it changes nothing: the identity matrix I from Part 3. Check: (|0⟩⟨0| + |1⟩⟨1|)|1⟩ = |0⟩×0 + |1⟩×1 = |1⟩, unchanged.
This is a handy trick: you can build any machine by listing "what goes in" (bras) and "what comes out" (kets), then adding the pieces.

4.6 Many qubits

For several qubits we just write their values side by side inside one ket. |01⟩ means "first qubit 0, second qubit 1". It is short for |0⟩ ⊗ |1⟩ (the tensor product from Part 3, 3.6.2).

Any two-qubit state is a mix of the four possible labels:

|ψ⟩ = a|00⟩ + b|01⟩ + c|10⟩ + d|11⟩

Each letter is the amplitude of that result, and the chance of each is its amplitude squared, just like before. The labels are written in binary, so with three qubits you'll see kets like |101⟩.

Example: the Bell state. (|00⟩ + |11⟩)/√2 says in one line: "50% both 0, 50% both 1, and never a mismatch". Written as a list of numbers it is [0.71, 0, 0, 0.71], which is much harder to read. This is the entangled pair from Part 3 (3.9).

4.7 Sandwiches ⟨ψ|A|ψ⟩: the average result

Put a machine between a bra and a ket of the same state and you get a "sandwich": ⟨ψ|A|ψ⟩. It gives the average result you would get if you measured A many times on copies of ψ. Its proper name is the expectation value.

Use the sign-flip matrix σz from Part 3 (3.5). Its eigenvalues are +1 for |0⟩ and −1 for |1⟩, so think of the results as +1 (read 0) and −1 (read 1). It leaves |0⟩ alone, puts a minus sign on |1⟩, and turns |+⟩ into |−⟩.
⟨0|σz|0⟩ = ⟨0|0⟩ = +1: always 0, so the average is +1.
⟨1|σz|1⟩ = ⟨1|(−|1⟩) = −1: always 1, so the average is −1.
⟨+|σz|+⟩ = ⟨+|−⟩ = 0: half +1 and half −1 average out to 0.

These are exactly the z coordinates on the Bloch sphere (Part 2, 2.5): top +1, bottom −1, equator 0. In the same way, ⟨ψ|σx|ψ⟩ gives the x coordinate and ⟨ψ|σy|ψ⟩ the y coordinate.
